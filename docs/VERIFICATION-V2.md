# v2 光影與素材升級驗證

日期：2026-10-19。這份文件記錄可直接核對的結果；v1 記錄留在 VERIFICATION.md，不代表目前畫質。

## 改動及已修正問題

- 12 張 Poly Haven CC0 PBR 貼圖、攝影測量岸石、PMREM HDR 環境照明；即時背景仍是 Sky，沒有背景照片。
- 2048／1024 日光陰影、1024／512 水面反射、實際場景深度折射與水路徑吸收、深度 AO、世界空間散射和焦散。
- 細葉棕櫚三種細節層級、原創分件海龜與活動鰭、具眼睛／鰭／尾擺的魚、彎曲分枝及桌狀／腦狀珊瑚、管海綿。
- 雲以 3D noise texture 加速世界空間 ray marching；森林 instancing、珊瑚 LOD、反射分層、高空細節剔除減少重複工作。
- 修正 UV 被模型最佳化移除、GLSL 插入缺換行、海底過曝、遠島方形棚架、LOD 相機參數及攝影機／深度 uniform 被 ShaderPass 複製的問題。
- 手機構圖修正海龜頭部裁切、海岸椰樹不可見；海龜鰭的三張連續畫面已人工檢視，沒有凍結或突然翻轉。
- 左上角 logo 保持移除。活動旅程的標題縮小，讓出場景。

## 測試

- npm test：3 項路徑／波面測試通過；連續性、地形淨空、兩次海面穿越及反向一致性。
- npm run build：TypeScript 與 Vite 正式打包通過。
- 本地 production preview 最終構圖回歸：[28 項通過](qa-v2-final/results.json)。包含滾輪、反向、播放／暫停、鍵盤、說明、音訊手勢、海面兩次穿越、延遲素材、單一 document。
- 1440×900、768×1024、390×844、320×640、844×390：無水平溢出，控制列與 Canvas 在範圍內；390／320px 發送 CDP 觸控事件，確認進度實際改變。
- reduced-motion 預設暫停；聲音在點擊前沒有 AudioContext。
- 六個已確認套用狀態的 Canvas 檢查（桌面／手機 × coast／reef／sky）及九個檔案證據檢查通過：[manifest](visual-v2-final/evidence.json)。開發版測試入口會固定時間並暫停模擬，渲染繼續；正式版會移除此入口。
- 本地回歸：0 JavaScript／Shader errors，0 失敗 HTTP 素材請求。NVIDIA／ANGLE 有一項不影響編譯的 X4122 浮點精度 warning；未聲稱 Console 完全沒有警告。
- 動畫使用未凍結的三張時間序列：[對照圖](motion-contact-v2.png)，原圖保留於 qa-v2-final/motion-turtle-*.png。這是分件鰭動畫，沒有骨骼或外部 animation clip。

視覺 harness 用於保護三幕取景與素材可見性；功能 QA 透過實際按鈕、滾輪及觸控，不以截圖代替操作驗證。本案不是遊戲，敵人、戰鬥、獎勵與遊玩機器人不適用。
